# 上位机代码结构

当前上位机为 .NET 9 / Windows Forms。界面仍使用同一个 `MainForm`，按职责拆分为 partial 文件；它们共享窗体状态，文件拆分本身不等于独立模块。

## 窗体与功能

- `MainForm.cs`：窗口入口、顶部与导航、公共界面组件及日志。
- `MainForm.Devices.cs`：设备列表、设备工作区和设备档案界面。
- `MainForm.Workbench.cs`：工作台工程操作与界面状态恢复。
- `MainForm.Acquisition.cs`：以太网连接、轮询和实时数据更新。
- `MainForm.Rs485.cs`：RS485 配置与传感器数据界面。
- `MainForm.Logic.cs`：联合控制器工作区及规则界面。
- `MainForm.LogicProjects.cs`：控制程序工程及文件管理。
- `MainForm.LogicEditor.cs`：编辑器交互、语法着色和查找。
- `MainForm.LogicCompiler.cs`：控制程序编译、下载及校验界面。
- `MainForm.Trends.cs`：趋势与记录页面。
- `MainForm.Serial.cs`、`MainForm.Test.cs`：串口及通信测试工具。
- `CodeEditorControls.cs`：代码编辑器的行号和缩略图控件。

## 独立业务组件

`ModbusTcpClient`、`Rs485ConfigurationProtocol`、`IoLogicCompiler`、`IoLogicProtocol`、`DeviceCatalog`、`WorkbenchProject`、`TrendRecorder`、`SerialConnection`、`SerialSimulation` 分别负责通信、编译、数据与持久化，不应反向依赖具体窗体控件。

新增功能优先使用独立的模型和服务，界面负责输入和展示；不要把协议解析、文件持久化和硬件操作直接堆在窗体事件里。后续应逐步减少各 partial 之间的共享可变状态，把采集、项目和规则编译改为具备明确接口的服务，再拆分页面控件；改动时验证断线、取消、设备切换和现有工程兼容性。
