# 板卡网络配置

固件 V1.2.11 使用 Modbus TCP 私有功能码 0x42 配置 IPv4 地址、子网掩码、网关和监听端口。旧版固件不支持该功能。无有效配置时默认 192.168.1.10、255.255.255.0、192.168.1.1、端口 5000。

上位机连接后点击“板卡网络配置”，读取现有配置，保存后板卡确认并复位。上位机会尝试新地址，读回一致后更新设备档案。新地址无法连接时检查电脑网段和 IP 冲突；不要误认为保存失败。

内部 Flash Bank 2 扇区 4/5（0x08180000–0x081BFFFF）是网络配置双槽，扇区 6/7（0x081C0000–0x081FFFFF）仍为 IO 规则。Keil 应用链接范围限制在 0x08000000–0x0817FFFF。下载工具若执行全片擦除，会清除两类配置；固件下载请检查擦除范围。

如果配置为无法访问的地址，可通过 SWD 使用烧录工具仅擦除 Bank 2 扇区 4 和 5，再复位以恢复默认网络参数；不要擦除扇区 6/7。此操作需确认工具显示的是对应的 Bank 和地址。当前未定义实体按键恢复功能。

RS485 采集表仍为易失配置，板卡复位后需重新下载，网络设置不会改变这一行为。
