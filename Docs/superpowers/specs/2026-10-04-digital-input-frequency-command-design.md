# 数字输入鉴频与并行指令输入设计

## 1. 目标

将八路隔离数字输入固定划分为以下产品功能：

| 通道 | 产品功能 | 输出数据 |
|---|---|---|
| DI1～DI2 | 高速脉冲计数、频率测量及软件鉴频 | 64位累计计数、频率、鉴频状态 |
| DI3～DI6 | 4位并行指令输入 | 0～15指令码、变更计数、最后变更时间 |
| DI7～DI8 | 普通开关量输入 | 消抖后的开关状态 |

原DI6～DI8增量编码器A/B/Z功能退出当前产品定义，相关运行代码、数据字段和寄存器定义一并移除，避免一个物理通道同时承担两种产品语义。

## 2. 高速脉冲鉴频

### 2.1 采集与频率计算

- DI1继续使用PE9/TIM1_CH1外部时钟计数。
- DI2继续使用PB7/TIM4_CH2外部时钟计数。
- 光耦输出下降沿为有效计数边沿。
- 硬件16位计数器由1 ms数字IO任务扩展为64位累计计数。
- 频率按100 ms窗口计算，单位Hz，分辨率10 Hz。
- 产品保证范围为0～2 kHz；超过2 kHz时只报告超量程，不保证计数和频率精度。

### 2.2 鉴频状态

每路输出独立状态：

| 状态 | 含义 |
|---|---|
| `NO_SIGNAL` | 达到无脉冲超时，未检测到连续输入信号 |
| `BELOW_LIMIT` | 有脉冲，但频率低于应用下限 |
| `IN_RANGE` | 频率位于应用下限和上限之间 |
| `ABOVE_LIMIT` | 频率高于应用上限，但未超过2 kHz硬件保证范围 |
| `OVER_RANGE` | 频率超过2 kHz硬件保证范围 |

每路使用独立配置：下限频率、上限频率、迟滞频率、无脉冲超时和连续确认窗口数。正式默认值如下：

| 参数 | 默认值 |
|---|---:|
| 下限频率 | 10 Hz |
| 上限频率 | 1800 Hz |
| 超量程门限 | 2000 Hz |
| 迟滞 | 10 Hz |
| 无脉冲超时 | 1000 ms |
| 状态确认 | 连续3个100 ms窗口 |

状态切换必须同时满足迟滞和连续确认条件，防止频率在阈值附近波动时反复报警。累计脉冲数不受鉴频状态影响。

## 3. 四位并行指令输入

### 3.1 位定义

DI3～DI6组成一个4位无符号指令码：

| 输入 | 权值 | 指令码位 |
|---|---:|---:|
| DI3 | 1 | bit0 |
| DI4 | 2 | bit1 |
| DI5 | 4 | bit2 |
| DI6 | 8 | bit3 |

计算式为：

`command_code = DI3 + 2*DI4 + 4*DI5 + 8*DI6`

全部无效时指令码为0，全部有效时指令码为15，共支持16种并行控制指令。

### 3.2 稳定判定

- 1 ms读取一次四位原始码。
- 原始码连续20 ms保持不变后才确认为新的有效指令。
- 稳定期间出现任意位变化，20 ms计时重新开始。
- 只有稳定指令发生变化时才增加指令变更计数并更新时间戳。
- 上电后的首个稳定码同样经过20 ms确认，不直接采用瞬时GPIO状态。

该整组判定用于抑制外部继电器、拨码开关或PLC多路输出切换不同步产生的过渡码。当前硬件没有独立选通信号，因此不承诺无延时的原子并行采样。

## 4. 普通开关量输入

DI7～DI8作为独立普通开关量输入，1 ms采样，连续5次一致后更新状态，典型消抖时间5 ms。其状态继续合并到八路输入总掩码中。

## 5. 软件结构

- `BSP/Src/bsp_pulse_counter.c`：只负责DI1、DI2硬件计数器。
- `Services/Src/digital_io_service.c`：负责计数扩展、频率计算、鉴频状态机、四位指令稳定判定及DI7～DI8消抖。
- `Services/Inc/digital_io_service.h`：定义鉴频配置、鉴频状态和完整输入快照。
- `Services/Inc/datahub.h`：发布跨任务数字IO快照，不保留编码器字段。
- `Application/Src/Task_digital_io.c`：1 ms驱动服务，10 ms发布DataHub快照。
- `Services/Src/modbus_register_map.c`：向上位机公开计数、频率、鉴频和指令数据。
- `BSP/Src/bsp_encoder_input.c`及其头文件退出正式工程和Keil工程文件。

## 6. Modbus寄存器

保留脉冲累计值和频率原地址，重新定义原编码器寄存器区域：

| 地址 | 数据 |
|---:|---|
| `0x0040～0x0043` | DI1的64位累计脉冲数，高字在前 |
| `0x0044～0x0047` | DI2的64位累计脉冲数，高字在前 |
| `0x0048～0x0049` | DI1频率，32位Hz |
| `0x004A～0x004B` | DI2频率，32位Hz |
| `0x004C` | DI1鉴频状态 |
| `0x004D` | DI2鉴频状态 |
| `0x004E` | 4位稳定指令码，范围0～15 |
| `0x004F` | 4位当前原始码，范围0～15 |
| `0x0050～0x0051` | 指令变更计数，32位 |
| `0x0052～0x0053` | 最后一次稳定指令变更时间，32位ms |
| `0x0054` | DI7～DI8消抖后状态，保留原bit6～bit7位置 |
| `0x0055` | 指令输入状态：bit0=已获得首个稳定指令 |
| `0x0056` | 服务状态：bit0=高速计数器就绪 |
| `0x0057` | DI3～DI8消抖/稳定后的低速输入状态 |
| `0x0058` | 两路鉴频状态打包：低字节DI1，高字节DI2 |

本次只读寄存器变更属于协议版本变化，上位机需要同步更新字段名称和解析逻辑。

## 7. 应用示例

- 流量计：DI1接脉冲流量计，累计脉冲换算累计流量，频率换算瞬时流量；鉴频状态用于停流、低流量、正常流量和超量程报警。
- 转速传感器：DI2接转速脉冲，频率换算转速；鉴频状态用于停转、低速、正常和超速判断。
- PLC模式指令：PLC四路数字输出连接DI3～DI6，直接选择0～15共16种设备工作模式。
- 拨码或旋钮指令器：四位编码开关连接DI3～DI6，作为本地配方、工位号或动作编号选择。
- 限位与联锁：DI7～DI8接行程开关、门禁或急停辅助触点，提供消抖后的开关状态。

## 8. 验证要求

1. 对DI1、DI2分别输入0、10、100、1000、1800、2000和高于2000 Hz信号，核对累计计数、频率和鉴频状态。
2. 在上下限附近往返扫频，确认迟滞及连续3窗口确认不会产生状态抖动。
3. 遍历DI3～DI6全部16种组合，确认指令码与位权一致。
4. 模拟四位输入不同步切换，确认仅在新组合稳定20 ms后发布一次。
5. 验证DI7、DI8在触点抖动条件下只输出稳定状态。
6. 通过Modbus逐项读取`0x0040～0x0058`，核对数据宽度、字序和状态编码。
