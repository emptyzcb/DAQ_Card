数据误差分析 · 使用与公式

一、数据准备
每行是一组一一对应的参考值 x 与测量值 y，两列必须使用相同单位和相同物理量。
可手工填写，或从 UTF-8 / GBK 编码的逗号分隔 CSV 选择参考值列与测量值列导入。
若各行使用同一参考值，可留空参考值列并填写“统一参考值”。
CSV 的两列必须已经逐行对齐；软件不会依据时间戳自动对齐或插值。
参考值是用于比较的基准，不一定是真实值。

二、误差指标
有符号误差 e = y - x；绝对误差 |e|；相对误差 e / x × 100%。
参考值 x = 0 时，该行相对误差不可计算，MAPE 与平均相对误差排除该行并显示排除数量。
偏差 = 平均(e)；MAE = 平均(|e|)；MSE = 平均(e²)；RMSE = √MSE。
中位绝对误差和 P95 是 |e| 的分位数，采用相邻样本线性插值。
sMAPE = 平均[200|y - x| / (|x| + |y|)]%，两者均为零的行不参与。
最大引用误差 = 最大 |e| / 满量程跨度 × 100%；跨度应为量程上限减下限，不是上限值。
误差样本标准差按 n-1 计算；测量值样本标准差描述所有输入值的离散程度。
不同参考点的数据混合时，测量值标准差不能作为仪表重复性。
R² = 1 - Σ(y - x)² / Σ(x - 平均x)²；参考值不变化时不可计算，也可能为负值。
皮尔逊 r 衡量线性相关，不等同于准确度；任一列没有变化时不可计算。
最小二乘拟合以参考值为 x、测量值为 y，输出 y = ax + b 的斜率与截距。
仅对同条件独立重复测量，给出 CV = 测量值样本标准差 / |测量值均值| × 100%。

三、重复测量与不确定度
仅当各次测量可视为独立、同条件重复测量、参考值一致且至少两组，才勾选对应选项。
此时 A 类标准不确定度 uA = 测量值样本标准差 / √n。
可输入其他来源合成后的 B 类标准不确定度 uB，它必须与测量值单位一致。
在 uA 和 uB 均已给出且视为独立时，uc = √(uA² + uB²)，扩展不确定度 U = k × uc。
本工具不自动评估参考标准、分辨力、环境、漂移、相关性或其他未输入的分量。
偏差不等于不确定度；本工具不自动将偏差修正或加入不确定度。
k = 2 并不在所有情况下保证 95% 覆盖概率，解释需符合分布和自由度等条件。
重复测量假设和 B 类分量应由使用者根据实验与仪器资料判断。

四、导出与边界
结果“—”表示样本不足、未提供参数或数学上不可计算，不代表误差为零。
导出 CSV 包含参数、指标、公式说明与逐行误差；输出数值采用双精度可往返格式。
当前最多导入 50000 行；超限、无效数字及非有限数值不会悄悄跳过。
