# 数据采集时间统一与联合控制：创新方法设计稿

本文的论文题目与研究主题固定为“数据采集时间统一与联合控制”。下文是拟实现、拟验证的方法，不代表现有固件已完成，也不代表已取得实板性能数据。

## 1. 建议主张的核心贡献

提出一种面向异构采集卡的规则时间契约方法：把采样时间不确定性传递到控制规则判定，由规则判定裕度反推允许的数据年龄，并将判定的有效期限同时绑定到输出命令和上位机核验记录，形成“统一时间表示、规则编译、三态判定、限期输出、证据回放”的处理过程。

研究问题是：板载模拟量、数字输入和外部 RS485 数据更新速度不同，采样时间的可知程度也不同。在不强制所有设备同步采样的条件下，如何判断现有数据是否仍足以支持同一时刻的联合控制，并控制为获得新数据而付出的等待和通信开销？

本课题的工程改进应落在“规则需要多新的数据、动作可以保持到什么时候、如何核验”这三个相连的问题上。四时间戳对时、数据年龄、区间运算、三态逻辑及基于变化界限计算信息有效期均已有研究，不将这些基础概念宣称为独创。

## 2. 必须修正的时间语义

采样时间、寄存器更新时间、报文到达时间和规则执行时间分别记录。报文到达时间不能直接作为采样时间。

尤其需要修正此前讨论中的一个简化：对普通 Modbus 传感器，采样时间不一定处于“请求发出至响应收到”之间。设备可能返回请求之前就已生成的缓存值；如果缓存更新时间没有上界，成功通信也不能证明数据是新采样的。

同样，多个时间区间存在交集，只能表示可能在同一时刻采样，不能证明实际同时采样；将几个时间戳调整成同一个数值也不会让实际采样变成同步。

## 4. 适用前提和结论边界

在实验与论文中明确以下条件：

1. 控制判定使用板卡单调时钟；所有参与运算的时间先换算到该时基。
2. 每个受保证的数据样本，其真实采样时刻包含在给定时间区间内。
3. 测量误差有界。该界限包括量化、标定残差以及实验要求覆盖的噪声等，不简单使用一个标准差冒充最大误差。
4. 对参与连续量判定的信号，指定并验证最大变化速率。实验信号可以由已知斜率的斜坡或三角波产生。历史上观察到的最大斜率不自动等于未来变化的上界。
5. 若讨论实际执行器动作时刻，必须另有从判定至动作完成的延迟上界。继电器触点动作与 GPIO 写入分别测量。
6. 若输入、时钟、通信或执行器超出上述假设，只能报告模型失配或能力边界，不承诺仍无误动作。

任意突变的数字输入不套用连续量变化速率公式。其时间语义以有完整性检查的边沿记录或明确的消抖逻辑状态为准。扫描输入不能证明两次扫描间没有短脉冲；中断或事件缓冲溢出后也不能继续声称事件完整。没有额外的最小保持时间等约束时，不能保证某个数字物理状态会持续到未来执行器动作时刻；此时只对已记录事件或当前逻辑状态及其反应延迟作限定表述。

量程饱和、错误数据、缺少年龄上界和时钟映射失效均应作为质量问题显式处理，不能继续使用原来的有限误差区间作确定判定。前端滤波和传感器内部平均引入的延迟，应在被测量定义、误差界或采样时间模型中处理。

## 5. 分层时间统一

### 5.1 板卡单调时基

选择可用硬件计时器构建单调计数器，处理回绕与原子读取。计时分辨率和真实时间准确度分别给出。先核对定时器资源，再决定是否采用微秒计数。

采样数据至少携带来源、值、序号、启动代次、采样时间下界 l、上界 u、接收时间和质量标记。一次规则求值使用冻结的数据快照，避免在执行同一条表达式时读到不同更新代次的数据。原子快照解决读数一致性，不等于物理同步采样。

### 5.2 上位机与板卡对时

定义四时间戳：t1 为上位机发送时刻，t2 为板卡接收时刻，t3 为板卡发送时刻，t4 为上位机接收时刻。

在短交换期间可近似忽略频率差时，沿用标准四时间戳公式：

    theta_hat = ((t2 - t1) + (t3 - t4)) / 2
    RTT = (t4 - t1) - (t3 - t2)

theta_hat 是板卡相对上位机的时钟偏移估计。仅凭四时间戳不能分离路径不对称，不能将 RTT 小或重复结果稳定等同于绝对同步准确。

若只假定两个方向的传输时间非负，则有：

    t3 - t4 <= theta <= t2 - t1

实际使用时向两端加入时间戳误差及交换期间的漂移界限。多次交换选择较窄的可行区间；不同交换的区间先按漂移上界传播到同一时刻，再检查是否相容。线性拟合可以改善偏移估计，但拟合残差不能单独充当严格误差上界。

板卡本地控制不随电脑校时跳变。板卡时钟到电脑时间的映射用于显示与回放，并携带当前不确定度；映射失效后扩大区间或标为未知。所有决策记录保留原始板卡时间和映射版本，避免以后校时使历史证据发生变化。

### 5.3 三类数据的采样时间区间

| 数据类型 | 时间表示及条件 |
| --- | --- |
| 板载 AD7606 | 以 CONVST 有效事件为参考，加入触发定位误差；使用过采样时说明有效采样窗口，不能只按读完时刻标记 |
| 数字输入 | 记录边沿或确认后的逻辑状态时间；扫描间隔、消抖延迟与物理边沿时刻分别说明 |
| 有可映射时间戳的 RS485 设备 | 将设备采样时间换算到板卡时基，加入设备对时和时间戳误差；有时间戳但无时钟映射仍不足以精确对齐 |
| 无时间戳但有缓存年龄上界 B 的设备 | 若请求完成时间为 q、响应完成时间为 r，且响应值在处理本次请求时的年龄确实不超过 B，可保守使用 [q-B, r]，再加入事件定位误差 |
| 缓存年龄、内部更新及冻结行为均无约束的设备 | 标为采样时间未知；可监视，不作为需要时间保证的规则证据 |

B 必须来自设备说明、受控实验条件或明确支持的设备实现。快速重复轮询不会自动缩小传感器内部缓存年龄。

## 6. 核心算法：把时间误差传递到当前值

设某连续输入采集值为 v_i，真实采样时刻 s_i 属于 [l_i, u_i]，测量误差不超过 e_i，信号最大变化速率不超过 L_i。

规则使用统一判定时刻 T，要求整个采样区间不晚于 T。若结论要覆盖执行器动作时刻，还要加入动作延迟上界 tau；仅讨论逻辑命令时可令 tau=0。

则在目标时刻 T+tau 的真实值位于：

    X_i(T+tau) = [v_i - E_i, v_i + E_i]
    E_i = e_i + L_i * (T + tau - l_i)

推导直接来自误差界与变化速率界：

    |x_i(T+tau) - v_i|
    <= |x_i(T+tau) - x_i(s_i)| + |x_i(s_i) - v_i|
    <= L_i * (T+tau-s_i) + e_i
    <= L_i * (T+tau-l_i) + e_i

这个区间不制造未测到的精确数值，而是保留当前值仍有多大不确定性。所有输入都被外推为同一个目标时刻的可行值范围，从而可以进行联合判定。

对于条件 x_i > h_i：

| 区间与阈值的关系 | 结论 |
| --- | --- |
| 区间下界严格大于 h_i | 确定满足 |
| 区间上界小于或等于 h_i | 确定不满足 |
| 区间跨过 h_i | 未知，需要进一步数据或按配置处理 |

AND、OR、NOT 使用三态逻辑：AND 有一项确定不满足即可确定不满足，全部确定满足才能确定满足；OR 有一项确定满足即可确定满足；NOT 保留未知状态。重复变量与相关性可能造成保守结果，但不能把保守结果冒充确定结果。

“未知”不能直接当作 false 跳入普通 else 分支。应由规则明确指定重新采集、短时保持或超时后的默认动作；保持不等于在所有应用中安全。论文不宣称本系统取得工业功能安全认证。

## 7. 可量化的工程改进：由规则反推数据时间预算

对于单个阈值条件，当 L_i>0 且样本与阈值之间的裕度大于测量误差时，该条件保持当前真假结论的一个保守时间预算为：

    A_i = (|v_i - h_i| - e_i) / L_i

实际判定需满足：

    T + tau - l_i < A_i

边界采用严格小于，避免将严格大于条件的等号边界误判为确定满足。若裕度不大于测量误差，重新获得同样读数也未必能作确定判断；若 L_i=0，则单独按静态值误差判定，不做除法。

例如 v=5.00 V、e=0.02 V、L=1 V/s：

| 对应规则 | 保守时间预算 |
| --- | --- |
| 电压大于 3.00 V | 小于 1.98 s |
| 电压大于 4.95 V | 小于 0.03 s |

同一个样本已过去 0.10 s 时，可以继续支持第一条规则，却不足以确定第二条规则。每条规则的时间要求由其数值条件和输入动态共同决定，不再仅由每个传感器的固定“500 ms 超时”决定。

这不是最优可用年龄的普适定理，而是在指定误差和变化速率前提下可计算、可验证的保守预算。

## 8. 有界等待与定向补采

一次决策先冻结快照并判断规则，再定位造成“未知”的必要输入。对仍需执行的规则，优先刷新预算即将到期或已经到期的输入；正常周期采集和公平性预算必须保留。

RS485 当前事务不被强行中断。新请求受总线容量、设备更新速率及每次事务的超时上界约束；设备内部没有更新时，盲目补采没有收益。某个确定为假的 AND 条件已足以排除规则时，不因其他无关条件未知而额外轮询。

每条规则另设等待截止时间。截止后仍无法判定，则执行预先规定的超时处理并记录原因，不能无限等待。瞬时连续量阈值是首期验证对象；“持续满足 100 ms”等时序规则需要整个区间的证据，不由两个端点成立直接推出。

定向补采是待比较的调度策略，不预先宣称最优或一定降低通信量。

### 8.1 将时间要求作为规则的可编译契约

上位机保存每个输入的时间能力：直接采样、源时间戳、有限缓存年龄或时间未知。规则编译器检查它们是否足以支持用户选择的时间保证，并生成阈值、误差界、变化速率界、等待期限及失效处理参数。

如果某设备没有可用的缓存年龄或时钟映射，编译器不得将其默认为“零延迟”；应指出该输入不能用于所选保证模式。不同规则可以对同一通道生成不同预算，避免把某个全局通道超时误当成所有规则共有的保证。

### 8.2 将判定有效期绑定到输出

对一个已经可以作确定判定的阈值条件，其结论在下列截止时间之前保持有效：

    d_i = l_i + (|v_i-h_i|-e_i) / L_i

复合规则的有效期按当前确定证据组合：AND 为真时取所有必要真条件的最早截止，OR 为真时可选一个真分支中较晚的截止；AND 为假时可选一个假分支中较晚的截止，OR 为假时取所有必要假条件的最早截止；NOT 保留截止时间。

这种组合给出保守证据期限，不宣称在存在变量相关性和复杂逻辑等价式时全局最优。未知分支不能单独支持输出。

板卡把输出动作与该截止时间绑定。若证据无法在到期前更新，必须按规则处理失效；不能因此前一次条件成立而无限保持输出。周期任务的调度间隔、刷新耗时以及动作建立或释放延迟都应预留在截止时间前。若只能保证 GPIO 命令的期限，则结论止于命令，不延伸为继电器触点一定及时断开。

### 8.3 可由上位机独立核验的动作记录

每次动作记录规则与配置代次、参与样本序号、时间区间、误差与速率参数、决策时刻、判定结果、证据截止及实际输出命令。上位机独立重算该记录，检查时间约束和规则结果是否相容。

该核验能复查程序是否遵守所声明的模型，不能凭日志证明外部传感器上报的值一定真实或模型边界一定成立。保留原始数据、时基和配置版本，才能复现异常原因。

## 9. 条件性结论与证明范围

在采样时间覆盖真实时刻、测量误差和变化速率界均成立、冻结快照和规则解释正确的前提下，对于本文支持的瞬时阈值及布尔组合规则：

- 输出“确定满足”，意味着所有符合上述区间的真实输入在指定目标时刻均满足该规则。
- 输出“确定不满足”，意味着所有符合上述区间的真实输入在指定目标时刻均不满足该规则。
- 输出“未知”，只表示现有证据不足；不能证明真实规则一定真或一定假。

证明由第 6 节的区间包含关系和三态布尔组合逐级推出。它证明的是规定模型内的逻辑判定可靠性，不是所有传感器、所有突变或任意通信故障下的系统安全。

即使两个采样时刻只差 1 ms，未限制变化速度的信号也可能在这期间多次跳变，所以仅有“小时间差”不足以证明当前联合条件为真。这也是增加规则裕度与变化速率约束的必要性。

## 10. 可复现的数值检查

同目录 sanity_check.mjs 使用固定随机种子生成 100000 组、每组两个有界变化输入，检查真实目标值是否落在计算区间中、确定判定是否与模型真值冲突、所给有效期内的判定是否保持，同时记录未知比例。另包含一个故意违反变化速率前提的反例。

它是推导和实现的数值检查，不是实板性能实验。数据分布人为指定，不可把它的错误率、覆盖率当作工业现场效果，也不能代替第 11 节的对照实验。

## 11. 实验设计：同时考察错误与可用性

### 11.1 对照组

| 组别 | 方法 | 用途 |
| --- | --- | --- |
| M0 | 按到达时间使用最新值 | 观察原始异步拼接问题 |
| M1 | 统一时钟，但仍直接使用最新值 | 分离“时钟对齐”本身的贡献 |
| M2 | 统一时钟，加固定年龄与时间差窗口 | 与常见保守门控比较 |
| M3 | 时间区间、规则裕度和三态判定 | 检验所提判定方法 |
| M4 | 在 M3 上增加定向补采 | 单独检验调度改进的收益与代价 |

对输出期限再进行一组消融：比较“判定后允许保持旧输出”与“有效期绑定输出”的差异，测量证据过期后的旧输出保持时长；若期限机制增加默认动作或短暂中断，也必须报告。

固定窗口应扫描多组参数，不能只挑一个故意很差的值。M3/M4 的配置也须在独立的调参记录上确定。各方法使用相同测试信号、故障脚本、设备参数和总线采集预算；另外报告自然开销下的结果，不能混淆“更高采样率”与“更好方法”。

### 11.2 测试场景

1. 已知变化速率的斜坡、三角波或低频连续信号，分别在远离阈值和接近阈值时判定。
2. 虚拟 RS485 从站独立配置内部更新周期、缓存年龄和通信响应延迟。仅改变返回延迟不能模拟内部采样陈旧。
3. 构造不同输入条件先后出现但不应共同满足的场景，检查错误拼接；用独立真值判定而不是被测系统自己的旧数据作答案。
4. 加入抖动、丢包、断线和时钟漂移，观察区间扩大、补采及超时处理。
5. 改变从站数与总线负载，测试性能退化，而不假定所有规则都可在期限内完成。
6. 故意输入超出变化速率界的突变或超龄缓存，报告方法的失效边界，不能删除不利记录。

### 11.3 指标与真值

| 指标 | 统计方式 |
| --- | --- |
| 错误触发 | 在独立真值为假时执行了激活动作；分别统计次数、持续时间和分母 |
| 按期正确动作 | 真值持续满足且达到预设响应期限时，是否已正确执行；一直等待也计入失败 |
| 正确动作延迟 | 从真值满足到实际命令或物理输出动作，分别统计中位数、P95/P99 |
| 未知与超时占比 | 明确区分“确定不满足”和“证据不足”，防止永不动作获得表面零误报 |
| 判定覆盖率 | 能作确定判断的比例，并与错误率一起给出 |
| 同步与时间区间 | 区间宽度、漂移及在有独立参考时的区间覆盖率；仅凭软件往返延迟不能声称绝对同步准确度 |
| 实现开销 | RS485 事务数、总线占用、规则执行耗时、缓冲区与内存开销 |
| 输出期限与核验 | 旧证据到期后的输出保持时长、动作证据可重算率及核验不一致原因 |

数值回放采用完整已知信号作真值；板端硬件实验使用独立信号源、参考测量或逻辑分析仪，记录采样触发、输入事件和输出动作。若没有共用参考，电脑与板卡绝对对时精度只报告为未验证，不能拿内部一致性代替外部准确性。

每组使用多次独立重复与多组相位、延迟种子，报告离散程度和置信区间。配对回放用于比较算法；实物测试用于验证时间定位、电气链路和执行延迟。模拟与实测结果分表呈现。

## 12. 板卡与上位机的工作分配

板卡实现统一计时、采样事件定位、带时间范围的数据快照、区间及三态判定、有界补采和实际输出。上位机实现时钟映射、传感器时间能力配置、规则参数配置、虚拟从站、判定过程回放和实验统计导出。

界面同时显示测得值、采样时间范围、当前值不确定范围、规则结论及等待原因。硬件与上位机共同构成闭环实验平台，各自都有独立可验证的工作量。

首期不实现通用控制器自动合成、完整时序逻辑证明或无限制任意 C 程序验证。先完成瞬时阈值、AND/OR/NOT 及显式超时动作，确保论文中心清晰。

## 13. 可用于开题报告的方法表述

针对工业现场板载模拟量与外部 RS485 数据采样时刻不一致、部分设备缺少原生时间戳的问题，提出一种面向异构采集卡的规则时间契约与联合控制方法。在统一单调时基下，区分采样、接收和执行时间，建立包含时间不确定性的样本表示；结合测量误差及信号变化速率约束，构建统一决策时刻的输入可行值区间，并由规则阈值裕度推导可接受的数据年龄。在此基础上，实现规则时间能力检查、三态判定及受截止时间约束的定向补采，将复合条件的证据期限绑定到输出命令，并由上位机重算动作记录。拟在 STM32H743 采集卡与上位机平台上，通过可控采样更新、通信延迟及故障注入实验，对误动作、按期响应、过期输出与采集开销进行对照评估。

## 14. 相关研究与主张边界

以下是本次查阅的相关一手资料，尚不构成穷尽性查新：

1. IETF, Network Time Protocol Version 4: Protocol and Algorithms Specification, RFC 5905. https://www.rfc-editor.org/rfc/rfc5905.html 。四时间戳、偏移、延迟与时钟滤波已有标准依据。
2. Yates et al., Age of Information: An Introduction and Survey. https://arxiv.org/abs/2007.08564 。数据年龄、采集及时性及其与估计和控制的关系已有系统研究。
3. Chiariotti et al., Query Age of Information: Freshness in Pull-Based Communication. https://arxiv.org/abs/2105.06845 。按查询需求评价新鲜度并非空白领域。
4. Grosen et al., Efficient Monitoring of Timed Properties. https://arxiv.org/abs/2206.14590 。存在时间不确定条件下的在线监测研究。
5. Baird et al., Interval Signal Temporal Logic from Natural Inclusion Functions. https://arxiv.org/abs/2309.10686 。区间信号及不确定条件的逻辑监测已有研究。
6. ROS 2 message_filters, ApproximateTime implementation. https://github.com/ros2/message_filters/blob/rolling/include/message_filters/sync_policies/approximate_time.hpp 。依据消息时间戳进行近似配对已有成熟实现。
7. Modbus Organization, Modbus Application Protocol Specification V1.1b3. https://www.modbus.org/file/secure/modbusprotocolspecification.pdf 。FC03/FC04 的标准读寄存器响应不自带通用采样时间戳或采样年龄保证；具体设备可自行扩展寄存器。
8. Malik, CIPS: Maximal Certified Persistence in Cyber-Physical Systems, 2026 年预印本。https://arxiv.org/abs/2608.06626 。该工作直接涉及变化界限、信息有效期限和执行延迟，因此“根据变化界限计算持久有效期”不能作为本文独有的理论创新；不因其预印本身份而忽略相关性，也不未经复核接受其所有普适或最优性主张。
9. Selvaratnam et al., MITL Verification Under Timing Uncertainty. https://arxiv.org/abs/2204.10493 。以命题成立时间的上下近似区间进行时间逻辑验证已有研究。
10. Zhang et al., Event-Triggered Control for Discrete-Time Delay Systems. https://arxiv.org/abs/2209.07560 。状态与时间相关的动态更新阈值已有研究，不把“动态而非固定阈值”本身当作原创。

本论文可以主张的是面向现有采集卡的时间能力建模、规则契约编译、限期输出及可核验上位机闭环的工程设计与对照验证。不能写“首次提出时间同步、数据年龄、信息持久有效期或区间逻辑”，也不能在尚未对照同类工作前声称该组合全球首创。若实验未显示覆盖率、响应、过期输出或开销方面的收益，应如实缩小贡献表述。
