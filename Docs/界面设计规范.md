# 界面设计规范（冷静浅色专业风）

本工程界面从"工业化高密度"改为"冷静、留白、克制"的专业控制台风格，参照 Linear / Notion / Vercel 控制台的组织方式：
中性灰白底、纯白卡片、发丝级描边、单一低饱和强调色、以大字号层级代替加粗线条。

所有颜色、字号、间距都集中在 `UiPalette.cs`，**页面里不要再写字面色值或字号**。

## 1. 颜色

| 令牌 | 用途 | 值 |
| --- | --- | --- |
| `Canvas` | 页面底色 | `#F5F6F8` |
| `Surface` | 卡片/表面 | `#FFFFFF` |
| `Sidebar` | 侧边栏 | `#FBFCFD` |
| `SurfaceMuted` / `RowHover` | 状态条、悬停 | `#F7F8FA` / `#F3F5F8` |
| `Border` / `BorderSoft` / `BorderStrong` | 卡片描边 / 行分隔 / 控件描边 | `#E6E9EE` / `#EFF1F5` / `#D5DAE3` |
| `Ink` / `InkSecondary` | 标题 / 正文 | `#16191F` / `#3C4350` |
| `Muted` / `Faint` | 次要说明 / 弱提示 | `#667085` / `#98A2B3` |
| `Accent` (`Blue`) | 唯一强调色（主按钮、选中态、焦点） | `#3E63DD` |
| `AccentSoft` (`BlueSoft`) | 选中背景、悬浮底 | `#EDF0FE` |
| `AccentText` | 选中态文字 | `#2E4DC8` |
| `Green` / `GreenSoft` | 正常/已连接 | `#1B835A` / `#E7F6EF` |
| `Warning` / `WarningSoft` | 待确认/进行中 | `#A97414` / `#FBF3E4` |
| `Red` / `RedSoft` | 异常/断开 | `#BE433D` / `#FCEDEC` |

规则：

- 强调色只用于"当前选中"和"主操作"，一屏不超过三处。
- 语义色只用于状态文字与小胶囊底色，不做大面积填充。
- 正文对比度不低于 4:1；弱提示（`Faint`）不用于需要阅读的文字。

## 2. 文字

| 令牌 | 用途 | 规格 |
| --- | --- | --- |
| `PageTitleFont` | 页面主标题 | 微软雅黑 18pt 粗 |
| `CardTitleFont` | 卡片/区块标题 | 11pt 粗 |
| `SectionFont` | 段落标题 | 12pt 粗 |
| `BodyFont` / `BodyStrongFont` | 正文、普通按钮 | 10pt / 10pt 粗 |
| `MetaFont` / `MetaStrongFont` | 说明、表头、单位 | 9pt / 9pt 粗 |
| `MetricFont` | KPI 数值 | Consolas 16pt 粗 |
| `MonoFont` / `MonoSmallFont` | 日志、寄存器值 | Consolas 10pt / 9pt |

字号下限 9pt。正文统一 10pt（原来 9pt 是"小气"的主要来源之一）。

## 3. 间距与尺寸

8px 栅格：`Space1..Space8` = 4 / 8 / 12 / 16 / 20 / 24 / 32。

| 项目 | 值 |
| --- | --- |
| 侧边栏宽 `SidebarWidth` | 248 |
| 页面内边距 `PagePadding` | 20（左右）、8/16（上下） |
| 卡片圆角 `CardCornerRadius` | 14（抽屉 12，按钮 8） |
| 按钮高度 `ControlHeight` | 36（工具栏按钮 38） |
| 侧栏导航项 | 224 × 42 |
| 表格行高 `GridRowHeight` | 46 |
| 表头高 `GridHeaderHeight` | 44 |

## 4. 结构

```
┌ 工程命令条（42px，白底 + 1px 底部发丝线）
└┬──────────────┬───────────────────────────────────────────────
 │ 侧边栏 248   │ 页头卡片（标题 18pt + 元信息 9pt + 右侧操作组）
 │ 品牌区 88    │ 网络设置抽屉卡片（默认折叠，点"网络设置"展开）
 │ 我的设备     │ 状态条 34px（状态胶囊 + 状态文字 + 日志开关）
 │ 设备页分组   │ ┌ 内容区 ─ 页面头部 ─ 工具条 ─ KPI 卡片行 ─ 数据卡片 ┐
 │ 通用工具分组 │ └ 通信日志卡片（可折叠）                          ┘
 └──────────────┴───────────────────────────────────────────────
```

- **侧边栏**：品牌区 → `我的设备` → 设备页分组（标题为设备名）→ `通用工具` 分组。选中项为浅强调底 + 左侧 3px 强调条 + 强调色粗体。
- **页头卡片**：左侧标题与元信息单行截断（不换行、不挤压右侧按钮），右侧操作组从右到左为主操作、次操作。
- **网络设置**：参数移入独立抽屉卡片，按需展开，页头不再被参数行撑高。
- **采集工具条**：采集周期、立即采集、开始轮询、实际间隔、工程量配置放在"实时监视"页头部，属于数据视图而不是全局页头。
- **KPI 卡片行**：链路状态 / 实际采集间隔 / AD7606 通道 / 数字 IO，数值用 Consolas 大字号。

## 5. 控件

新增自绘控件（`UiControls.cs`）：

- `CardPanel`：圆角白卡 + 发丝描边，替代 `Panel` + `RoundControl`。
- `NavItem : Button`：侧栏导航项，自绘图标 + 文字 + 选中胶囊（`Active` 属性）。
- `StatusPill`：状态胶囊（圆点 + 文字 + 软底色），当前位于底部状态条。
- `StatTile`：KPI 卡片（标题 / 大字数值 / 提示）。
- `NavigationGlyph`：静态矢量图标绘制（20×20 网格，任意尺寸与颜色）。

按钮语气用 `UiPalette.StyleButton(button, ButtonEmphasis.Primary/Secondary/Quiet/Danger/Ghost)`，
不要直接设置 `BackColor`（会破坏禁用态与悬停态的颜色还原）。

## 6. 自检

- `tests/UiDesignAudit`：渲染整窗，遍历全部 9 个页面，报告字号过小、控件过矮、文字对比度不足，输出控件树与几何信息。
  ```powershell
  dotnet build tests/UiDesignAudit/UiDesignAudit.csproj -c Debug
  dotnet tests/UiDesignAudit/bin/Debug/net9.0-windows/UiDesignAudit.dll `
      bin/Debug/net9.0-windows/IndustrialFieldDataAcquisitionTerminal.dll .\audit.txt 1480 940
  ```
- `tests/HeaderLayoutSmoke`：1100/1400/1920 宽、100/125/150% 字号下页头不裁剪、不重叠、文字不超高。
- `tests/UiLayoutProbe`：页面结构、表格、日志、趋势与编辑器的行为回归。

新增页面或控件时：先跑 `UiDesignAudit`，确保 `=== PROBLEMS ===` 为 `none`。
