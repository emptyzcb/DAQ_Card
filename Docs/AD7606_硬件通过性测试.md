# AD7606 驱动与硬件通过性测试

## 实板接口

| 信号 | MCU 引脚 | 方向 |
|---|---|---|
| OS0 / OS1 / OS2 | PD4 / PD5 / PD6 | 输出 |
| RANGE | PD7 | 输出 |
| CONVST_A、CONVST_B | PD8，共用 `AD_CV_AB` | 输出 |
| RESET | PD9 | 输出 |
| SCLK | PE3 | 输出 |
| DOUTA(DB7) / DOUTB(DB8) | PE5 / PE4 | 输入 |
| CS | PE6 | 输出 |
| BUSY | PE7 | 输入 |

AD7606 工作在串行模式。DOUTA 顺序输出 AIN1~AIN4，DOUTB 同时输出 AIN5~AIN8；每次转换使用 64 个 SCLK 周期读完 8 路 16 位数据。

## 上电测试流程

1. 初始化 GPIO，默认量程为正负 10 V、无过采样。
2. RESET 拉高后恢复低电平。
3. 检查空闲 BUSY 必须为低。
4. 在 `AD_CV_AB` 产生低到高转换沿。
5. 检查 BUSY 是否拉高，再检查它是否在超时前回到低电平。
6. CS 拉低，以 SPI Mode 0 时序同时读取 DOUTA、DOUTB。
7. 检查 8 路数据是否全部固定为 `0x0000` 或 `0xFFFF`。
8. 自检通过后进入 10 ms 周期采样；单次采样失败只累计错误，不停止后续重试。

## Modbus 观察值

- 保持寄存器 `0x0003`：AD7606 自检结果。
- 保持寄存器 `0x0010~0x0017`：AIN1~AIN8 的有符号 16 位原始值。
- 状态寄存器 `0x0000` 的 bit1：AD7606 服务已运行；bit3：最近一次采样成功。

自检码：`0` 未执行，`1` 通过，`2` BUSY 上电即为高，`3` 转换后 BUSY 未拉高，`4` BUSY 未按时拉低，`5` BUSY 握手通过但八路数据全部为 `0x0000/0xFFFF`。

自检码 `5` 说明数字握手已经成立，但模拟输入、参考电压、DOUT 焊接或输入接地状态仍需继续确认。AD7606 没有芯片 ID 寄存器，因此软件不能仅凭固定数据证明整个模拟通道准确；最终应给任一路施加已知电压并核对转换值。

## 调试串口日志

调试日志从 USART2 输出：PA2 为 TX、PA3 为 RX，参数为 `115200 8N1`。上电时输出接口模式、自检码和首帧 8 路原始值，之后每秒输出一次采样计数、错误计数和最新 8 路原始值。USART1 继续专用于 RS485 Modbus，不输出调试文本。
