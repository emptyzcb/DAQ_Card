# 工业现场数据采集终端

Windows 上位机通过标准 Modbus TCP 连接采集板卡。

## 默认连接

- 板卡 IP：`192.168.1.10`
- TCP 端口：`5000`
- Unit ID：`1`
- 建议轮询周期：`250 ms`

## 功能

- 采集 8 路 AD7606、8 路数字输入及 IO 运行状态。
- 配置最多 32 个 RS485 Modbus RTU 传感器采集项。
- 支持 FC03/FC04、从站地址、起始寄存器、数量和轮询周期设置。
- 查看 RS485 传感器最新值、通信状态和错误计数。
- 编译并下载 IOCF v2 联合控制程序。
- 规则可控制 4 路继电器、4 路晶体管、0~10 V 和 0~20 mA 输出。

## 输出控制

`0x0002` 仅用于读回 8 路数字输出状态。所有物理输出都由 IO 联合控制器的已下载程序驱动。

## RS485 地址区

| 地址 | 含义 |
| --- | --- |
| `0x0080~0x027F` | 32 个采集项的最新数据，每项 16 个寄存器 |
| `0x0280~0x0285` | 活动数量、容量、代次、暂存数量和应用命令 |
| `0x0300~0x03FF` | 传感器身份、状态、错误计数和时间戳 |
| `0x0400~0x04BF` | 待下载的 RS485 轮询表 |

## 构建

```powershell
dotnet build IndustrialFieldDataAcquisitionTerminal.csproj -c Release
```

## 工作台工程（.daqproj）

顶部“工程”菜单可新建、打开、保存、另存工程，也可打开最近工程。

- “保存工程”打包设备档案、各设备的以太网参数和 RS485 采集表、当前联合控制器源码及库文件/手册，以及趋势通道选择、时间窗口、当前页面。
- 编辑器里尚未写入源码文件的修改也会保存到工程文件。保存工程不会覆盖原源码；首次保存或打开总工程后，编辑器使用独立工作副本。IO 编辑页的“保存”写入工作副本，保留整个实验环境仍需点击顶部“保存工程”。
- 打开工程后，联合控制代码在本机独立工作副本中编辑；设备档案与 RS485 配置在该工程内管理。“返回本机环境”可回到原来的本机设备列表。
- 工程打开后保持板卡离线，不自动启动轮询，也不自动下载规则或 RS485 配置。需要连接时，点击“连接以太网”。串口工具独立运行。
- 顶部工程名称后的 `*` 表示有未保存修改。退出或切换工程时会提示保存。已有工程保存时保留上一版 `.bak`；外部文件变化会阻止直接覆盖。
- 工程包含当前选中的一套联合控制代码，不包含其他代码工程、历史 CSV 数据、串口通信参数或虚拟从站配置。历史记录仍保存在原记录目录。
- 文件可复制到另一台安装相同或兼容版本工作台的电脑，通过“打开工程”恢复。

## 工程量换算

进入设备的“实时监视”，点击右上角“工程量配置”。选择通道，填写名称、单位和两组对应的原始点、工程值；软件使用线性插值，超出区间时线性外推，不进行裁剪。AD7606 输入点是有符号原始码，RS485 输入点是单个无符号 16 位寄存器；不自动识别多寄存器、浮点或字节序。

原始值保留，实时监视/RS485 表、趋势和 CSV 增加工程量。只有本次连接成功下载的 RS485 采集表且配置未改变时才显示 RS485 换算；重新连接后需重新下载采集表。修改换算配置会开始新趋势记录，旧 CSV 保留；无效采样不会当作有效值。

换算按设备分别存储，并随 `.daqproj` 保存。换算仅影响上位机显示和记录，不修改 MCU 采样或联合控制器使用的数据。为确保物理量正确，请用实测点或设备技术资料填写原始码与工程值的对应关系。

## CAN 通用工具

左侧“通用工具 → CAN”通过 PEAK PCAN-Basic API 使用 PCAN-USB 兼容设备。PCAN-Basic 5.1.0 接口 DLL 来自 PEAK-System 官方发布包并按 x64/x86/ARM64 分目录部署；设备驱动需要事先安装。官方资料：https://www.peak-system.com/products/software/development-packages/pcan-basic/

- 插入适配器，点击“刷新通道”，选择通道和波特率后点击“连接 CAN”；默认 Classic CAN、500 kbit/s。CAN 通道与板卡以太网、普通串口工具相互独立。
- 显示标准/扩展、数据/远程帧，支持手动发送，ID 和数据均为十六进制。远程帧 DLC 为请求长度，不携带数据。发送成功表示已加入驱动发送队列，并不单独证明对端已处理。
- 默认按 ID 汇总显示最近帧、次数及相邻接收周期（由设备相对时间计算），也可切换为逐帧记录。发送区显示最近 200 条提交记录，双击可载入发送参数。
- 选择接收帧查看字节、16 位大小端及有/无符号解释；物理含义与缩放需查设备协议，软件不假定业务含义。
- 表格最多保留 3000 帧，超过后移除较早帧并显示数量；CSV 仅导出当前保留的帧。主机时间是上位机收到/提交时刻，设备计时为适配器返回的相对计时，不是绝对日期。
- 本工具目前支持 Classic CAN，不支持 CAN FD/DBC 文件。对总线发送报文会影响其他节点，请确认连接与波特率后使用。

### CAN 进阶功能

- 连接前可勾选“只监听”；软件核验适配器硬件模式并禁止发送。只监听是否工作以适配器和驱动支持为准。
- 输入十六进制起止 ID 后点击“应用过滤”，只影响屏幕显示；原始接收记录和连续记录不受过滤影响，状态/错误帧仍显示。
- “发送计划”从主界面的当前帧添加条目，可保存/打开 `.canlist`，并手动启动或停止选中条目。周期范围 100–3600000 ms，使用 Windows 定时器，精度受系统负载影响；延迟时跳过错过的周期，不进行突发补发。断开、只监听、Bus-off 或发送失败时停止，重新连接或打开列表不会自动发送。
- “开始记录”选择 CSV 后后台连续记录全部收发帧；停止或退出时完成队列写入。缓冲区满或文件写入失败会停止并明确提示，不能保证超出缓冲能力的帧都被记录。原来的“导出 CSV”只导出当前内存中的最近 3000 帧。
- 解释区域提供字节、16/32 位大小端有符号/无符号整数、32 位浮点与 ASCII 的原始解释；不能自动判断实际信号含义，也不支持 DBC 或 CAN FD。

## 通用网络与数据工具箱

左侧“工具箱”提供四个独立工具，和板卡以太网连接、串口、CAN 可同时使用：

- TCP/UDP 调试：支持 TCP 客户端、TCP 服务端和 UDP，UTF-8 或 HEX 发送、文本或 HEX 显示。TCP 接收以数据块显示，TCP 没有固定报文边界；TCP 服务端发送给全部已连接客户端，UDP 保留报文边界。本机端口 0 由系统分配。
- 数据格式转换：支持 16/32/64 位有符号、无符号整数及 32/64 位浮点数。小端表示整个数值字节倒序，交换 16 位字表示反转寄存器顺序；不自动推断设备的数据格式。
- Modbus TCP 虚拟从站：默认监听 127.0.0.1:1502，仅本机可访问；改为本机网卡 IP 或 0.0.0.0 才能由外部连接。可以添加最多 32 个不同 Unit ID，每行按空格分隔填写线圈、离散输入、保持寄存器和输入寄存器。支持 01、02、03、04、05、06、0F、10 功能码；请求写入后点击“刷新数值”查看。停止后可编辑并重新启动，配置在当前运行期间有效。
- 网络诊断：查看本机网卡、IPv4、掩码及网关，按指定主机和端口检查 DNS、Ping 和 TCP 连接。Ping 被防火墙禁用时 TCP 仍可能正常；TCP 检查仅连接，不发送业务报文。

### 采集时序与趋势间断

网络参数和采集控制独立显示。采集周期为上位机轮询启动的目标周期；实际间隔根据相邻轮询开始时的单调计时测量，可能受网络、处理耗时和系统调度影响。完成一次读取后按目标节拍安排下次读取，若错过周期则跳过，不补发。停止采集、重启采集或通信失败后，趋势曲线从新段开始，不跨越无数据的时间段连线；CSV 的 SegmentId 可用于区分各段。暂停查看只是冻结图表，采集仍由开始/停止轮询控制。

曲线与 CSV 使用上位机接收到对应数据的时间，不是板卡内 AD7606 转换时刻。上位机读取的是板卡最近值，目标周期设得较长可能丢失中间波形或峰值；增加上位机轮询频率也不能恢复没有传出的样本。精确波形采样需要板卡缓存每个样本并附板卡采样时间或序号，再批量传输。

### 串口通信测试

在“通信测试”页直接选择 USB-RS485 串口、波特率、数据位、校验位和停止位，然后点击“启动模拟”。默认 115200、8N1；可以按实际主站修改。停止模拟会关闭该页的串口。通信测试和普通串口工具使用独立连接，可以同时使用不同端口；同一个 COM 口不能被两处同时打开。

### 高频轮询显示

以太网接收到的有效快照仍按轮询结果逐次加入趋势记录与 CSV；实时监视表格和指示灯的绘制最高约 5 次/秒，停止轮询时显示最后一次已接收快照。通信日志按批次刷新并保留原有显示上限，日志窗口中的 TX/RX 数与采样点数不是同一个概念。
