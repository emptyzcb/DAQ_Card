# 工业现场数据采集终端

这是采集板卡的 Windows Modbus RTU 上位机，通信链路为：

`MCU -> RS485 -> 485 转串口模块 -> 电脑 COM 口`

## 直接运行

双击：

`publish/IndustrialFieldDataAcquisitionTerminal.exe`

该文件是 `win-x64` 自包含单文件，不需要另外安装 .NET Runtime。

## 默认通信参数

- 串口：选择 485 转串口模块对应的 COM 口
- 波特率：115200
- 数据格式：8N1
- 从机地址：1
- 轮询周期：1000 ms

## 当前功能

- 自动轮询设备状态、数字 IO、AD7606、IMU 和姿态寄存器
- 显示每一帧 Modbus RTU 的 TX/RX 十六进制日志
- 显示 CRC、超时和设备异常
- 支持写入数字输出寄存器 `0x0002`
- 支持“立即采集”和清空通信日志

## 寄存器

| 地址 | 含义 |
| --- | --- |
| `0x0000` | 设备状态 |
| `0x0001` | 数字输入位图 |
| `0x0002` | 数字输出位图，可写 |
| `0x0010~0x0017` | AD7606 8 路原始值 |
| `0x0020~0x0025` | IMU 6 路原始值 |
| `0x0030~0x0032` | Roll/Pitch/Yaw，单位 0.01° |
